# F1-Pitwall
Real-time F1 telemetry analysis with AI race engineer coaching, pit wall dashboard, and corner-by-corner driver comparisons. AI-powered F1 telemetry system with live speed, throttle, tire degradation tracking, and race engineer voice coaching.

## Features

- **Interactive Onboarding**: New users get a guided tour of all app features with F1-themed design
- **Real-Time Telemetry Dashboard**: Live F1 racing data monitoring
- **Driver Performance Metrics**: Speed, RPM, throttle usage, gear shifts, and DRS activations
- **Session Information**: Current race details, track temperature, and driver count
- **Top Lap Times**: Fastest lap times with gaps to pole position
- **Live Connection Status**: Real-time backend connection monitoring
- **F1-Themed UI**: Racing-inspired design with checkered patterns and team colors
